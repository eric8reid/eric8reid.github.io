Reid OS Uploader

Uses YouTube API Services

Reid OS Uploader is a small personal tool. It uploads short videos that the channel owner made themselves to the owner's own YouTube channels, using the official YouTube Data API (videos.insert only).

It is not a public service: only the channel owner uses it, from their own computer. It does not access anyone else's account and does not read or display YouTube data.

Before using it, read the Privacy Policy and Terms of Service. By using it you agree to be bound by the YouTube Terms of Service.
