Privacy Policy: Reid OS Uploader

Last updated: November 21, 2026

What the app does

Reid OS Uploader is a personal tool used only by its owner to upload videos the owner created to the owner's own YouTube channels.

YouTube API Services

Uses YouTube API Services This app uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Google data it accesses

It requests only the https://www.googleapis.com/auth/youtube.upload scope, which lets it upload videos and set their title, description and privacy. It does not read your other videos, comments, subscribers, analytics, email, contacts or any other Google data.

What is stored, where, and for how long

  • The OAuth refresh token Google issues is stored only on the owner's own computer, in Windows Credential Manager. It is never sent anywhere except Google's own APIs.
  • For each upload, the returned video ID and link are written to a local log file on the same computer, so the owner knows what was posted.
  • No YouTube data is collected, displayed, analyzed, sold or shared. There is no server, database, cookies or analytics.

Deleting your data

  • Revoke access at any time in your Google security settings: https://myaccount.google.com/permissions. Revoking makes the stored token useless immediately.
  • The owner deletes the stored token from Windows Credential Manager and the local upload log within 7 days of revoking access or stopping use of the app.
  • To ask about deletion, open an issue on GitHub.

Sharing

No data is sold, shared, or transferred to anyone. Google user data is used only to upload the owner's videos, in line with the Google API Services User Data Policy, including the Limited Use requirements.
