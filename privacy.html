Privacy Policy: Reid OS Uploader

Last updated: November 21, 2026

What the app does

Reid OS Uploader is a personal tool used only by its owner to upload videos the owner created to the owner's own YouTube channels.

Google data it accesses

It requests only the youtube.upload permission, which lets it upload videos and set their title, description and privacy. It does not read your other videos, comments, subscribers, email, contacts or any other Google data.

How data is stored

The sign-in token Google issues is stored only on the owner's own computer, in Windows Credential Manager. It is never sent to any server other than Google's own APIs. The app has no database and no analytics.

Sharing

No data is sold, shared, or transferred to anyone. Google user data is used only to upload the owner's videos, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access makes the stored token useless.

The app also uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
